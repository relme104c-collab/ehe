==========================================================
  SOALKIT PORTABLE - Pembuat Soal & Surat Otomatis
  Untuk Windows 7 / 8 / 10 / 11 (spesifikasi rendah pun jalan)
==========================================================

CARA MENJALANKAN
----------------
1. Buka folder ini, lalu klik dua kali "SoalKit.bat"
   (atau buka "SoalKit.html" langsung dengan browser).
2. Tidak perlu instalasi, tidak perlu internet, tidak perlu
   hak administrator. Cukup browser (disarankan Chrome atau
   Edge; di Windows 7 gunakan Chrome/Firefox versi terakhir
   yang mendukung Windows 7).
3. Seluruh aplikasi hanya SATU file HTML, jadi sangat ringan.

STRUKTUR FOLDER (PORTABLE)
--------------------------
  SoalKit.html        -> aplikasinya (jangan diubah)
  SoalKit.bat         -> pembuka cepat (opsional)
  config.js           -> KONFIGURASI terpisah dari aplikasi:
                         nama & alamat sekolah, gambar kop,
                         margin (default 2 cm semua sisi)
  bank-soal\soal.js   -> BANK SOAL: semua soal tersimpan di sini
  surat\surat.js      -> SURAT: semua surat tersimpan di sini
  BACA-SAYA.txt       -> file ini

FITUR
-----
* Tab "Soal"   : menulis soal pilihan ganda A-B-C-D untuk
                 kelas 7, 8, dan 9 (SMP). Preview naskah
                 tampil langsung di samping kanan.
* Tata letak pilihan bisa dipilih: 2 kolom (A B / C D)
                 atau 4 baris (A, B, C, D ke bawah).
* Soal bisa ditata 1 kolom atau 2 kolom per halaman.
* Gambar bisa ditambahkan pada soal maupun pada masing-
  masing pilihan (tombol 🖼), dan posisinya bisa diatur
  sebelum atau sesudah teks. Ukuran gambar bisa diatur
  sendiri (lebar dalam cm) serta perataannya kiri/tengah/
  kanan — perataan ini berlaku di kedua mode posisi
  (sebelum maupun sesudah teks) karena gambar selalu
  tampil utuh satu baris penuh, tidak lagi berdampingan
  dengan teks sehingga rapi dilihat.
* Tombol "Sisip di Teks" (🖼): menyisipkan gambar di
  tengah kalimat, tepat di posisi kursor di dalam teks
  soal/pilihan (klik dulu di dalam kotak teks pada posisi
  yang diinginkan, lalu klik tombolnya).
  Gambar besar otomatis dipadatkan agar file tetap ringan.
* Teks soal dan pilihan bisa diformat Tebal (B), Miring (I),
  dan Garis Bawah (U): blok teksnya lalu klik tombol
  B / I / U, atau langsung pakai Ctrl+B / Ctrl+I / Ctrl+U.
* Judul Naskah juga bisa diformat Tebal/Miring/Garis Bawah
  dan bisa multi-baris: tekan Enter di dalam kotak judul
  untuk pindah ke baris berikutnya (judul tidak lagi
  memanjang satu baris saja).
* Teks cerita / bacaan (mis. soal cerita) ditampilkan dalam
  kotak berbingkai: bisa disisipkan sebelum soal mana pun,
  dengan jarak kiri/kanan kotak dan perataan teks yang
  bisa diatur.
* Baris identitas (Nama, No. Peserta, Kelas, Hari/Tanggal)
  bisa dinyalakan/dimatikan satu per satu.
* Footer naskah: teks footer + nomor halaman otomatis
  (hanya angka) di setiap halaman. Jarak footer dari tepi
  bawah halaman juga bisa diatur (dalam cm, default 1 cm).
* Tab "Surat"  : membuat surat resmi sekolah (undangan,
                 pemberitahuan, dll.) dengan kop dan tanda tangan.
* Lembar jawaban berbentuk LINGKARAN A B C D otomatis
  ditambahkan di halaman terakhir naskah soal.
* Bisa menambahkan halaman KUNCI JAWABAN untuk versi guru.
* Kop surat bisa berupa gambar: buka tab "Pengaturan",
  klik "Pilih Gambar Kop" (PNG/JPG, misal hasil scan kop).
* Margin kiri-kanan-atas-bawah, default 2 cm, bisa diubah,
  langsung terlihat di preview.
* Tombol "Cetak / PDF": pilih printer untuk mencetak langsung,
  atau pilih "Microsoft Print to PDF" / "Save as PDF" untuk
  menyimpan menjadi file PDF.

MENYIMPAN DATA (FOLDER)
-----------------------
* Sementara: otomatis tersimpan di perangkat (localStorage)
  setiap kali Anda mengetik.
* Permanen ke folder: buka tab "Pengaturan" -> klik
  "Hubungkan Folder Aplikasi" -> pilih folder tempat
  SoalKit.html berada (sekali saja). Setelah itu:
  - tombol "Simpan ke Folder" menulis langsung:
      bank-soal\soal.js  (semua soal)
      surat\surat.js     (semua surat)
      config.js          (pengaturan + kop)
  - atau centang "Simpan otomatis ke folder" agar tersimpan
    sendiri setiap ada perubahan.
  Fitur ini didukung Chrome dan Edge. Di browser lain,
  aplikasi otomatis mengunduh file soal.js dan surat.js
  yang tinggal Anda pindahkan ke folder masing-masing.
* Mengimpor kembali: klik tombol "Impor" lalu pilih file
  soal.js / surat.js / config.js / .json.

MEMINDAHKAN KE PERANGKAT LAIN
-----------------------------
1. Klik "Simpan ke Folder" (atau "Ekspor Config").
2. Salin SELURUH folder ini ke flashdisk / perangkat baru.
3. Di perangkat baru, buka SoalKit.html — config dan data
   langsung terbaca otomatis karena filenya memang terpisah
   dari aplikasi.

CATATAN CETAK
-------------
* Ukuran kertas diset A4. Pastikan pilihan kertas di dialog
  cetak juga A4 dan skala 100% agar margin 2 cm sesuai.
* Windows 10/11 punya printer "Microsoft Print to PDF" bawaan.
* Windows 7: gunakan menu "Save as PDF" di dialog cetak
  browser (Chrome/Firefox), atau instal printer PDF gratisan.
