Teks cerita (mis. bacaan soal cerita) tampil dalam kotak berbingkai. Atur posisi penyisipan, jarak kiri/kanan, dan perataan pada setiap kotak.
Daftar Soal (Pilihan Ganda A–D)
Tandai salah satu pilihan sebagai kunci jawaban bila halaman kunci ingin dicetak.

Identitas Sekolah / Kop Surat

Margin Dokumen (cm)

Standar dokumen sekolah: 2 cm untuk semua sisi. Perubahan langsung terlihat di preview.

Penyimpanan Portable

config.js (di folder aplikasi) menyimpan identitas sekolah, kop, dan margin — terpisah dari aplikasi.
bank-soal/soal.js menyimpan semua soal, surat/surat.js menyimpan semua surat.
Klik Hubungkan Folder Aplikasi lalu pilih folder tempat SoalKit.html berada. Setelah itu tombol Simpan ke Folder menulis ketiga file tersebut langsung ke tempatnya.
